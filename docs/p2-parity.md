## Writes and equivalent bearer routes (not false auth blockers)

`Write::Board` enters the **existing mutation queue**. It checks `/user/context`
against the frozen account before sending, keeps idempotency keys/retry state
across restart, validates acknowledgements, and never changes visible server
state merely because a request was enqueued. Form results are consumed once.
Agent assignment is optimistic with a before snapshot and permanent-denial
rollback; human assignment must preserve agent rows (never assign an agent's
owner as a human). New-label acknowledgement transactionally queues assignment
of its real ID; a failed create never invents an ID or attaches a phantom label.

All paths below are MCP-relative; route auth is **validateMcpRouteAuth** (aliased
as validateMcpAuth), except `/tasks/update` uses **validateMcpAuth** directly.
