# Command and keyboard gap acceptance

Written before implementation. No VPS builds/tests/lint/app launches and no
owner-laptop access. Verification runs only in public GitHub Actions.

## Checks

1. Trace web creation defaults, quick-entry targeting, placement and save routes
   from `/home/valentin/projects/hypertask/src`, citing file:line. Mirror only
   authoritative cached inputs; never infer favorites, active views or ranks.
2. Close locally implementable command/keyboard gaps with GPUI key input and
   observable UI/SQLite assertions in CI. Creation must not invoke AI compose.
   Self assignment uses explicit assign intent, never replaces the cached
   human list, and must preserve uncached concurrent assignees after restart.
   Preserve drafts on cancellation/failure. Unsupported server operations stay
   explicitly blocked with their HTPR-7699 authorization boundary.
3. Preserve the unchanged reference-content layout comparer and rail checks.
   Download baseline and final `layout-dumps`; report raw per-screen counts and
   unsampled-rail source comparison separately. No source-unsupported values,
   removed controls, altered tolerances or fixture manipulation.
4. Fetch/rebase before every push. Open a draft PR. Require exact-head CI,
   every required job and artifact, and the supplied SHA-bound wait receipt.
   A failed or skipped required job is not completion.

## Sequence and ownership

- Read source and blockers before implementing a bounded change.
- Keep typed native command/action state; add no placeholder command rows.
- Verify each implementation unit in GitHub CI before extending it.
- Own command/shortcut gap code and these parity ledgers. `look9` owns visual
  edits; `nativeci`, `prewire`, and `updater` own their independent paths.
- One worker keeps targeting, defaults and keyboard state consistent. No
  delegated workers. Unavailable Cursor built-ins use serial source/diff review.

Prove It Works selects real exact-head CI artifacts, not compilation alone.
Sequence Verifiable Units selects small checked commits. Model the Domain
selects explicit draft/placement state rather than reusing AI compose.

of the web update route exposed an additional concurrent-person risk in using a
replacement assignee list. The follow-up uses explicit assign intent and adds
